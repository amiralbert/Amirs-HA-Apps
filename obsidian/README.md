# Home Assistant App: Obsidian

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

**Experimental.** [Obsidian][obsidian] running in your browser, based on the
[LinuxServer.io Obsidian image][lsio]. Your vault lives in `/share/obsidian`, so
GitHub Sync and Hermes Agent can work on the same files.

See [DOCS.md](DOCS.md) for setup and known limitations.
