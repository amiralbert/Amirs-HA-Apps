# Home Assistant App: Hermes Agent

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

[Hermes Agent][upstream] by Nous Research, packaged for Home Assistant, with
persistent state, Git credentials and workspaces in `/share/hermes`.

Combine it with the FreeLLMAPI app in this repository to use free LLM tiers.

See [DOCS.md](DOCS.md) for setup and configuration.
