# Home Assistant App: Tolaria

![Supports amd64 Architecture][amd64-shield]

**Experimental.** [Tolaria][tolaria] (Markdown knowledge base with Git
integration) running in your browser. Tolaria is a desktop app without a server
mode, so the app streams the Linux desktop build through the
[LinuxServer.io Selkies][selkies] web desktop, like the Obsidian app. Your vault
lives in `/share/tolaria`, so GitHub Sync and Hermes Agent can work on the same
files.

See [DOCS.md](DOCS.md) for setup and known limitations.
