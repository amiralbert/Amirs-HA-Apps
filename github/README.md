# Home Assistant App: GitHub Sync

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Keeps GitHub repositories in Home Assistant's `/share` folder in sync: clone,
periodic pull and, optionally, auto-commit and push. Handy for an Obsidian
vault or for Hermes Agent workspaces. The `gh` CLI is included.

See [DOCS.md](DOCS.md) for setup and configuration.
