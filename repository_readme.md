## 🪄 Installation (Der magische Weg)

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Famiralbert%2FAmirs-HA-Apps)

## 📦 Verfügbare Add-ons

Aktuell beinhaltet dieses Repository die folgenden Add-ons:

### 🤖 Hermes Agent

Ein leistungsstarker Agent für Desktop-Automatisierung und KI-Workflows direkt integriert in dein Home Assistant Ökosystem.

* **Architektur:** `aarch64`, `amd64`
* **Features:** API-Key gesichert, anpassbares Logging.

### 📝 GitHub Obsidian Sync

Synchronisiert deine Obsidian Vaults sicher und zuverlässig über GitHub lokal auf deinen Home Assistant (im `/share/` Ordner), damit deine Notizen immer Teil deiner Smart Home Backups sind.

* **Architektur:** `aarch64`, `amd64`
* **Features:** Automatischer Intervall-Sync, Token-basierte Authentifizierung.

### 🧠 FreeLLM API

Stellt die FreeLLM API lokal im Netzwerk bereit. Perfekt für lokales LLM-Routing und KI-Automatisierungen in Home Assistant, ohne auf externe Cloud-Dienste angewiesen zu sein.

* **Architektur:** `aarch64`, `amd64`
* **Features:** Konfigurierbares Port-Mapping, leichtgewichtiger Flask-Server.

## 🛠️ Manuelle Installation

Falls der magische Button bei dir nicht funktioniert, kannst du das Repository auch manuell hinzufügen:

1. Öffne deine Home Assistant Oberfläche.
2. Navigiere zu **Einstellungen** -> **Add-ons**.
3. Klicke unten rechts auf den Button **Add-on Store**.
4. Klicke oben rechts auf die drei Punkte (Menü) und wähle **Repositories**.
5. Füge die folgende URL hinzu:

   ```text
   https://github.com/amiralbert/Amirs-HA-Apps
   ```

6. Klicke auf **Hinzufügen**.
7. Lade die Seite neu. Meine Add-ons sollten nun ganz unten im Store auftauchen!
